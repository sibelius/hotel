# Hotel Mariah

A hotel management game (Portuguese UI): check guests in at the reception, pick up items at the stations and deliver them to guests, earn coins and gems, level up and buy upgrades in the shop.

Run: `python3 -m http.server 5179` in this folder and open http://localhost:5179 (the 3D version loads Three.js as an ES module, so it needs a server).

- `index.html`: **3D version** built with Three.js. Click to walk, drag to rotate the camera, scroll or pinch to zoom, right-click to pan.
- `index-2d.html`: the original **2D version**
